## 当前阶段：M0 与 M1 已完成，下一步 M2

已完成：

- Tauri 2 + React + TypeScript + Vite 初始化。
- Memento 应用标识、窗口标题和基础视觉壳。
- 左侧导航和主要功能入口占位。
- 产品、架构、开发和 ADR 文档系统。
- M0：产品场景细化（日记、未来信件、导出备份恢复）、SQLite 与编辑器选型 ADR、版本基线与验证命令。
- M1：Rust 数据目录初始化与 SQLite 迁移、五个日记命令、“今天”页真实创建与编辑、800 ms 自动保存与失败重试、切页与关闭前 flush、设置页显示数据位置。

尚未完成：

- 富文本编辑器、图片与标签；Tiptap 计划在 M2 引入。
- 回收站、时间地图、搜索和未来信箱的数据流。
- 导出、备份和恢复。
- 自动化测试、CI 和 Windows 安装发布验收。

前端构建和 Rust 检查已通过；M1 的 A01–A05、A15 桌面验收证据见[迭代记录](development/iterations/iteration-001.md)。导航中未接入的入口、版本号和占位页面均不代表功能完成。

## P0：MVP 交付阶段

阶段按依赖推进，阶段编号在任务、验收和迭代记录中保持一致。

| 阶段 | 主要交付 | 完成门槛 | 状态 |
| --- | --- | --- | --- |
| M0 开发准备 | 细化产品场景、完成关键选型 ADR、建立验收数据与最小验证流程 | 能说明写入、保存成功和失败恢复的行为，M1 任务可执行 | 已完成 |
| M1 可靠保存 | SQLite 与迁移、最小日记创建/编辑、自动保存、重开 | 真实磁盘数据完整，失败与重试可验证 | 已完成 |
| M2 日记闭环 | 格式编辑、图片、标签、回收站与恢复 | 中文长文与多图可编辑、保存、删除和恢复 | 待开始 |
| M3 回看与检索 | 时间线、月历、日期详情、关键词/标签/日期筛选 | 多条路径均可找到同一批真实记录 | 待开始 |
| M4 未来信箱 | 写信、锁定、到期打开、回应 | 时区和边界正确，重开后原信与回应完整 | 待开始 |
| M5 导出与恢复 | Markdown 与图片、完整备份、校验与恢复 | 全新空间实际恢复后内容与关系完整，失败保留当前空间 | 待开始 |
| M6 Windows 发布 | 全链路回归、故障与性能检查、安装升级和发布说明 | 全部 P0 验收通过，无发布阻断缺陷 | 待开始 |

下一步进入 M2：“创建日记 → 自动保存 → 关闭重开 → 继续编辑”已打通，接着补齐格式编辑、图片、标签与回收站。备份覆盖范围和数据一致性从 M0/M1 开始设计，完整实现和恢复验证在 M5 完成；不能因此把备份降为可选。

容量假设为 1 名开发者、每周约 4 个有效开发日；含缓冲暂估约 11–16 周。尚未确定启动日期，M1 完成后重估，阶段通过验收后才更新状态。详细工作量和风险见开发计划。

## P1：MVP 稳定后评估

- 收藏卡片、主题收藏册和月份切片。
- 全局快速捕捉、最近阅读位置和草稿恢复细节。
- 应用锁和本地凭据保护；加密方案需要单独设计。

上述能力未开始实施；收藏册占位入口不构成提前交付。

## P2：暂不进入实施

- 自由画布、胶带和贴纸。
- 云同步、移动端和多人协作。
- AI 整理、摘要和年度回顾。
- 公开分享和社交功能。

进入 P1/P2 前重新确认产品范围、数据影响和需要的 ADR，不将这些能力插入当前 P0 关键链路。
