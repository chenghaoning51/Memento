# ADR-0001：选择 Tauri + React + TypeScript

- 状态：Accepted
- 日期：2026-10-17

## 背景

Memento 需要一个 Windows 优先的桌面应用，同时希望使用成熟的前端工具快速迭代界面，并将本地文件、SQLite 和备份恢复放在可靠的系统边界内。

## 决定

使用 Tauri 2 作为桌面框架，React + TypeScript + Vite 作为前端，Rust 负责本地系统能力和数据访问。

## 原因

- 可以复用前端生态建立编辑器、时间地图和收藏页面。
- Rust 适合处理本地文件、SQLite、备份和未来的加密能力。
- Tauri 应用体积和权限边界适合本地优先产品。
- 不需要在第一版引入账号、云服务或独立后端。

## 取舍

- 前端和 Rust 之间需要维护类型化命令边界。
- Windows 构建依赖 WebView2 和 C++ 工具链。
- 桌面端测试比纯 Web 应用更复杂，需要同时验证前端和 Tauri 命令。

## 影响

第一阶段先保留清晰的 UI、应用服务和 Tauri 命令分层。SQLite、Tiptap 和附件能力按功能单独接入，不在脚手架阶段全部耦合。
