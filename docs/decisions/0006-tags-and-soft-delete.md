# ADR-0006：标签存独立表，日记只做软删除

- 状态：Accepted
- 日期：2026-10-17

## 背景

M2-03 要让日记能打标签，并能把日记删进回收站再恢复。M0 的数据模型把 `tags` 与 `entry_tags` 列为目标设计，把 `deleted_at_utc` 列为软删除字段，但没有定下三件具体的事：标签在数据库里是一行一个还是拼成字符串；同名标签怎么判定"同一个"；删除日记时对正文、附件行和标签关系做什么。

约束来自已有实现和产品文档：标签要能跨日记复用，否则"按标签找回"在 M3 无法实现；标签输入是自由文本，中文和英文混用；`entries`、`attachments` 已经落地，改动要能通过一次迁移增量完成；永久删除的产品规则仍未确定（见 [ADR-0005](0005-attachment-files.md)）。

## 决定

- 标签独立建表：`tags(id, name, normalized_name)`，`entry_tags(entry_id, tag_id)` 用复合主键。日记正文里**不**存标签字符串。
- 规范化规则固定为：去首尾空白，把内部连续空白折叠成一个空格，得到显示用的 `name`；再小写得到 `normalized_name`，并加唯一约束。写入前先按 `normalized_name` 查已有行，有就复用，没有才插新行。显示名沿用第一次写入的写法。
- 长度上限 32 个字符，按规范化后的字符数计算；超限返回 `AppError::TagTooLong`，文案"标签最多 32 个字符。"，不写入任何行。规范化后为空的输入被忽略，并原样返回该日记当前的标签列表。
- 标签在确认和移除时立即写库，**不**跟随正文的 800 ms 自动保存节奏；正文保存失败不会回滚已确认的标签，反之亦然。两者是独立的事务。
- 删除日记是软删除：只写 `deleted_at_utc`（RFC 3339 UTC）。正常列表按 `deleted_at_utc IS NULL` 过滤，回收站按 `deleted_at_utc DESC, id DESC` 列出。恢复即写回 NULL。
- 软删除**不动**正文、附件行、附件文件与 `entry_tags` 关系；恢复后三者原样回来。永久删除与孤儿附件清理仍不实现。

## 原因

- 标签独立成表才能做 M3 的"按标签筛选"和"标签交集"；拼成字符串则每次筛选都要全表扫描并重新分词，且改名要改写所有日记。
- 规范化与唯一约束放在数据库层：应用层查重有并发窗口，唯一索引是最后一道保证；把规则写成 `clean`/`normalized` 两个纯函数，输入、去重、未来搜索都调同一份，不会出现"输入时算一套、比较时算另一套"。
- 大小写只影响比较、不影响显示：用户写 "Travel" 就该看到 "Travel"，而不是被改成 "travel"。
- 32 字符上限是给标签栏和未来的筛选列表留的展示空间，不是数据库限制；超限在命令层就拒绝，避免半截标签入库。
- 标签立即写库而不跟随自动保存：标签是一次明确的确认动作（Enter 或逗号），用户预期它当场生效；如果跟随正文节奏，正文保存失败时标签会连带消失，反而更难解释。
- 软删除只写一个时间戳，是因为删除必须可撤销，而附件清理不可撤销。正文和附件一起留在原处，恢复才能做到"和删除前一样"，这也是 A09 的通过标准。

## 备选方案

- **把标签拼成逗号分隔字符串存进 `entries`**：实现最快，但按标签筛选要全表扫描，改名要改写全部日记，也无法给标签加稳定 ID 供未来备份校验。
- **`entry_tags` 只存标签名不存 ID**：改名和备份恢复都要靠字符串匹配，中文与大小写差异会让"同一个标签"变成多个。
- **规范化时连显示名一起小写**：去重更简单，但用户输入的 "Travel" 会被改成 "travel"，标签栏显示的不是自己写的东西。
- **删除时物理删行并清理附件**：无法撤销，且与"永久删除规则未定"冲突；一旦误删，用户的图片会真的消失。
- **删除时清空正文或把附件标记为待清理**：恢复会变成"部分恢复"，与产品承诺的"正文、图片和标签关系保持不变"直接矛盾。

## 影响

- 迁移 v3 新增 `tags`、`entry_tags` 两张表与 `entry_tags_by_tag` 索引；`PRAGMA user_version` 变为 3。
- Rust 侧新增 `src-tauri/src/tags/mod.rs`（`Tag`、`MAX_TAG_CHARS`、`clean`、`normalized`）与 `tags/repository.rs`（`list_for_entry`、`add`、`remove`）；`entries/repository.rs` 新增 `list_deleted` 与 `set_deleted_at`；`error.rs` 新增 `TagTooLong`。
- 新增六个 Tauri 命令：`list_deleted_entries`、`delete_entry`、`restore_entry`、`list_entry_tags`、`add_entry_tag`、`remove_entry_tag`。
- 前端新增 `src/features/today/TagBar.tsx` 与 `src/features/trash/TrashPage.tsx`；导航增加"回收站"页面，日记页脚增加"移到回收站"。
- M3 的标签筛选可以直接 `JOIN entry_tags`；M5 的备份必须连同 `tags`、`entry_tags` 一起打包，并在恢复后保持标签 ID 与关系不变。
- 孤儿标签（不再被任何日记引用）不会被自动删除；是否清理留到标签管理能力出现时再定。
