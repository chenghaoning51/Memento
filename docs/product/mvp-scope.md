# MVP 范围

## 目标

在 Windows 桌面上完成一条可靠闭环：创建记录、保存内容、按时间找回、写给未来、导出带走。

## P0：第一版必须完成

### 日记编辑器

- 创建、编辑和删除日记。
- 标题、正文、引用、分隔线、链接、图片和标签。
- 自动保存状态、撤销与恢复。
- 删除进入回收站，支持恢复。

### 时间地图

- 月历显示有记录的日期。
- 时间线按日期浏览。
- 进入某一天后显示当天全部记录和附件。
- 日历中的首图或色块作为视觉提示。

规则见[时间回看](time-browsing.md)。

### 搜索与筛选

- 关键词、日期范围和标签筛选。
- 结果显示标题、日期、摘要和首图。
- 第一版优先保证中文短语搜索可靠，不急于引入复杂分词依赖。

规则见[搜索与筛选](search.md)。

### 未来信箱

- 创建信件并设置开启日期。
- 到期前显示为锁定状态。
- 到期后阅读原信并追加回应。

### 本地数据和导出

- SQLite 保存元数据和正文结构。
- 附件存放在应用数据目录。
- 导出 Markdown 和图片。
- 导出完整备份并从备份恢复。

## 场景细化

产品语义的细化文档：

- [日记](journal-entry.md)：创建、自动保存状态、切页关闭、撤销与恢复、回收站、日期与时区。
- [时间回看](time-browsing.md)：时间线、月历与进入某一天的规则。
- [搜索与筛选](search.md)：关键词、标签与日期范围，结果状态与边界。
- [未来信件](letters.md)：开启时刻、锁定与到期、回应、时区与夏令时边界。
- [导出、备份与恢复](backup-and-export.md)：导出范围、备份清单、恢复预检与失败回退。

## P1：核心闭环稳定后加入

- 收藏卡片和主题收藏册。
- 规则生成的月份切片。
- 全局快速捕捉。
- 最近阅读位置和草稿恢复细节。
- 应用锁和本地凭据保护。

## P2：暂不进入实施

- 自由拖拽画布、胶带和贴纸系统。
- 云同步、移动端和多人协作。
- AI 自动整理、摘要和年度回顾。
- 公开分享和社交功能。

## MVP 验收

在完全离线的情况下，用户可以写入中文长文并插入多张图片；关闭并重新打开应用后内容完整；按日期、标签和关键词可以找回；未来信件在到期后可阅读和回应；完整备份恢复后正文、图片和关系不丢失。
