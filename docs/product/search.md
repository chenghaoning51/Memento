# 功能：搜索与筛选

- 状态：M3-02 实现关键词、标签与日期范围筛选。
- 相关：[MVP 范围](mvp-scope.md)、[日记](journal-entry.md)、[时间回看](time-browsing.md)、[数据模型](../architecture/data-model.md)、[验收清单](../development/acceptance.md)。

## 目的

写到第几百篇之后，"我记得写过"比"我要按顺序翻"更常见。搜索要能用一个记得的词、一个标签或一段日期，把那一批记录重新捞出来，并且结果能直接点进去继续写。

## 搜索框

- 顶部是关键词输入框，占位文案"搜索正文里的字词"。输入即查，停止输入后自动刷新，不需要按回车。
- 关键词是子串匹配，不要求整词：搜"梧桐"能命中"窗外的梧桐叶被打湿"。
- 匹配不区分大小写，也不受换行和连续空格影响：正文里跨行的短语仍然能被搜到。
- 标题与正文一起参与匹配。关键词里的 `%`、`_` 按字面匹配，不当作通配符。
- 关键词为空表示不限关键词，此时只看标签和日期条件。

## 标签筛选

- 标签以胶囊按钮平铺在关键词下方，按名称排序，来自所有日记的标签合集。
- 点一下选中，再点一下取消；选中的标签显示为实心样式。
- 同时选中多个标签时取**交集**：结果必须同时拥有这些标签。
- 标签按钮只在选中时高亮，不显示每篇的数量。

## 日期范围

- "从"与"到"两个日期输入，都是本地日历日期；只填一边表示只限起点或只限终点。
- 区间包含两端：从 10-01 到 10-03 会命中 10-03 当天的记录。
- 清空日期输入即取消该边界。

## 结果

- 结果按日记日期从新到旧排列，同一天内后写的在前，与时间线一致。
- 每一行显示日期、标题（没有标题时用摘要或"空白日记"）、创建时间与首图；有标题时摘要作为第二行显示。
- 右上角显示当前状态：有条件且已读完显示"找到 N 篇"，还在分批加载显示"已读 N 篇"，无条件时显示"全部记录"，没有命中显示"没有找到"。
- 一次取 40 篇，滚动到底自动接着取；条件变化时从头重查，正在进行的旧请求不会覆盖新结果。
- 点任意一行进入那一篇日记，页头显示"返回搜索"，侧栏高亮停在"搜索"。

## 边界

- 搜索不返回回收站里的日记；恢复之后会重新出现在结果里。
- 不搜附件文件名、图片内容或标签名本身（标签有独立的筛选按钮）。
- 不做相关度排序、不做高亮、不做分词；中文短语的可靠性靠子串匹配保证。
- 第一版是本地全表扫描，篇数很大时的性能基线在 M6 记录，届时再评估是否换索引。
