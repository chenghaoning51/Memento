# 功能：时间回看

- 状态：M3-01 实现时间线、月历与日期详情。
- 相关：[MVP 范围](mvp-scope.md)、[日记](journal-entry.md)、[数据模型](../architecture/data-model.md)、[验收清单](../development/acceptance.md)。

## 目的

日记按日期写下来，就必须能按日期找回来。时间回看提供两条路径：一条顺着时间往下翻，一条在月历上看哪天写过。

## 时间线

- 按日记日期从新到旧排列；同一天有多篇时，后写的排在前面。
- 一次取 40 篇，滚动到底自动接着取下一批，底部显示「到底了」表示没有更多。
- 每一行显示首图（没有图片时用一个小圆点占位）、摘要和创建时间；空日记显示「空白日记」。
- 日期按天分组，组标题是「2026年10月17日」这样的本地日历日期。
- 点任意一行进入那一篇日记，不是当天最后一篇。

## 时间地图（月历）

- 默认打开当前月，左右按钮翻月，可跨年。
- 网格从当月第一天所在周的周一铺到当月最后一天所在周的周日，相邻月的日期用浅色显示，点它们同样能进入那一天的日记。
- 有记录的日期显示当天篇数，并在有首图时用首图做底色；今天是唯一带描边高亮的格子。
- 顶部显示「这个月 N 篇」，只统计属于当前月的记录，不把相邻月格子的篇数算进来。
- 没有记录的月份显示「这个月还是空白」，不显示 0。

## 进入某一天

- 从时间线或月历进入后，日记页标题变成那一天的日期（不是「今天」），右上角显示该日日期，列表显示这一天的全部日记。
- 页头出现返回按钮，文案按来源区分：「返回时间线」或「返回时间地图」；侧栏高亮也停在来源页。
- 这一天没有记录时显示「这一天还没有记录」「补写这一天，也来得及。」和按钮「写这一天的第一篇」，创建出的日记归属这一天，不是今天。
- 直接点侧栏「今天」回到今天页，返回按钮消失。
- 从某一天进入后新建或编辑，仍然走同一套自动保存与切页规则：切页前先落盘，失败就停在原处。

## 边界

- 时间线与月历都不显示软删除的日记；回收站是独立入口。
- 时间线只按时间排序，不提供关键词、标签或日期范围筛选；检索走独立的[搜索](search.md)页面。
- 月历一次读取整屏范围内的日期汇总，不做虚拟滚动；数据量增大后的性能基线在 M3-03 记录。
