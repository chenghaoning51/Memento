# 功能：导出、备份与恢复

- 状态：M0 确定范围与语义；M5 实现。数据设计从 M1 开始考虑。
- 相关：[MVP 范围](mvp-scope.md)、[数据模型](../architecture/data-model.md)、[验收清单](../development/acceptance.md)。

## 目的

用户可以把自己的内容带走，也可以在换机或重装后完整还原。

## 导出

- 范围：用户选中的日记。
- 产物：Markdown 文件 + 图片文件，写入用户选择的目录。
- 图片使用相对路径引用，导出后不依赖应用即可打开。
- 富文本降级规则：标题→`#`，引用→`>`，分隔线→`---`，链接→`[文本](url)`，图片→`![](相对路径)`。
- 目标目录存在同名文件时追加序号，不静默覆盖。
- 目标不可写时报错，不留下被当作成功的半成品。

## 备份

- 范围：完整空间——`memento.db` 的一致性快照、`attachments/`、`thumbnails/`、`manifest.json`。
- `manifest.json` 记录应用版本、模式版本（`PRAGMA user_version`）、文件清单和每个文件的 SHA-256。
- 备份期间发生编辑或附件导入时，以备份开始时刻的快照为准；成功的备份内部不能出现引用缺失。
- 只有校验通过、完整写完的备份才标记为有效；失败不产生“看起来成功”的备份。

## 恢复

- 按完整空间恢复设计，不做增量合并。
- 预检：manifest 版本是否受支持、文件清单是否齐全、校验值是否一致。
- 恢复前自动备份当前空间，保证可以回退。
- 预检失败或写入中断时，当前空间保持可打开，不留下半新半旧的数据。
- 恢复完成后重开应用核对正文、原图、标签、回收站、信件与回应。

## 不做什么

- 不做云端同步、选择性合并、加密备份；这些需要独立的安全与同步设计。
