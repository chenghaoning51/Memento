# 产品

Memento 是一个 Windows 优先、离线可用的私人时光收藏室：用很低的成本留下生活片段，再在未来重新遇见它们。

- 写下来的内容可靠地留在自己的设备上。
- 时间让过去可以被重新找到，而不只是堆在列表里。
- 未来信件让内容随着时间增加新的关系。

默认没有账号、点赞、公开动态和连续打卡；用户可以漏记，也可以只保存一句话。本地保存不等于加密，真正的加密与应用锁需要独立的安全设计，产品文案不得把“本地保存”描述成“已加密”。

## 范围

### P0：1.0.0 已交付

| 能力 | 内容 | 规则 |
| --- | --- | --- |
| 日记 | 创建、编辑、标题、引用、分隔线、链接、图片、标签、自动保存、回收站 | [功能规则](features.md#日记) |
| 时间回看 | 时间线、月历、进入某一天 | [功能规则](features.md#时间回看) |
| 搜索与筛选 | 关键词、标签、日期范围组合检索 | [功能规则](features.md#搜索与筛选) |
| 未来信箱 | 写信、锁定、到期阅读、独立回应 | [功能规则](features.md#未来信箱) |
| 带走 | Markdown 导出、完整备份与恢复 | [功能规则](features.md#导出备份与恢复) |

MVP 的验收标准：完全离线时能写入中文长文与多张图片，关闭重开内容完整；按日期、标签和关键词可以找回；未来信件到期后可阅读和回应；备份恢复后正文、图片与关系不丢失。

### P1：核心闭环稳定后评估

收藏卡片与主题收藏册、规则生成的月份切片、全局快速捕捉、最近阅读位置与草稿恢复、应用锁与本地凭据保护。“收藏册”导航入口是占位页，不构成已交付。

### P2：暂不进入实施

自由拖拽画布与贴纸、云同步与移动端、多人协作、AI 整理与年度回顾、公开分享与社交。

## 设计原则

- **像收藏品，而不是数据库**：页面有排版与纸张层次，但装饰服务于内容，编辑和检索速度优先于拟物效果。
- **二次元的，但首先得好读**：配色走柔和粉彩（樱花粉配天空蓝），面板用半透明磨砂加大圆角，背景有缓慢飘落的花瓣。装饰只做在背景层：不压字、不抢焦点、不接管点击；系统开启“减少动态效果”时花瓣直接隐藏。
- **像私人空间，而不是社交平台**：不打卡、不排名、不公开。
- **时间本身就是功能**：内容应该能通过日期、信件与未来的收藏关系再次出现。
- **本地优先，但不夸大安全承诺**：默认离线、不建账号、不主动上传。

## 不做什么

不用打卡和连续天数推动使用；不把首页做成数据统计仪表盘；不让自由拼贴阻塞写作；不把 AI 摘要当作核心价值。
