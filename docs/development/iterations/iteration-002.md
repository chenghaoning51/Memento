A07 明细：

- 一次选两张图，编辑器里同时出现两张（此前逐张插入会互相覆盖，本轮修复）。正文 image 节点的 attrs 为 `{src, alt, title, width, height, attachmentId}`，`src` 是 `http://attachment.localhost/<附件 ID>`。
- 数据库 `attachments` 表 5 行，磁盘上 `attachments/<日记 ID>/<附件 ID>.<后缀>` 5 个文件、`thumbnails/<附件 ID>.jpg` 5 个文件，数量一致；缩略图长边 320。
- `entries.cover_attachment_id` 等于正文第一张图的附件 ID，列表条目显示 34 px 首图。
- 把两张源图改名移走后刷新页面、关闭进程再重开，三张图 `naturalWidth`/`naturalHeight` 与源图尺寸一致，首图同样正常。
- 导入 400×300 BMP 时界面提示「只支持 PNG 和 JPEG 图片。」，正文与已保存内容不受影响，数据库也没有多出附件行。
- 全部日记的 `content_json` 中不存在 `data:image` 或 base64 片段。
