## 2026-10-17 M0 开发准备

- 新增[日记场景细化](product/journal-entry.md)：同日多篇、空日记不自动删除、四态保存状态（已保存/编辑中/保存中/保存失败）、800 ms 停止输入自动保存与最多 5 秒强制保存、切页与关闭前 flush、区分编辑撤销与保存失败恢复与回收站恢复。
- 新增[未来信件场景](product/letters.md)：开启时刻按创建时区换算 UTC、锁定/到期/已打开三状态在启动与进入页面时重算、到期后只能追加回应。
- 新增[导出与备份场景](product/backup-and-export.md)：Markdown 导出规则、完整空间备份清单、恢复预检与失败不半新半旧。
- 新增 [ADR-0002 SQLite 存储](decisions/0002-sqlite-storage.md)：Rust 侧 rusqlite + bundled，迁移使用 `PRAGMA user_version`。
- 新增 [ADR-0003 编辑器与正文格式](decisions/0003-editor-and-body-format.md)：M1 使用原生 textarea 与带版本的 `content_json`，M2 再评估 Tiptap。
- 建立最小质量流程与版本基线。

## 2026-10-17 M1 第一条可靠保存链路

- Rust 侧新增数据目录初始化：启动时在应用数据目录创建 `Memento Library/`，打开 `memento.db`，启用 WAL 与外键，按 `PRAGMA user_version` 顺序执行迁移；未知高版本直接启动失败，不写入。
- 新增五个 Tauri 命令：`library_info`、`list_entries`、`get_entry`、`create_entry`、`save_entry`。
- “今天”页接入真实数据：按本地日历日期列出当天日记、新建日记、切换日记、编辑正文。
- 自动保存：停止输入 800 ms 保存，连续输入最多 5 秒强制保存；同一时刻只有一个在途请求，排队写入最新内容；失败保留输入并显示“重试保存”。
- 切页与关闭窗口前 flush：保存失败时阻止切换并保留当前输入。
- 新增“设置”页，显示数据目录、数据库文件与模式版本。
- 新增窗口权限 `core:window:allow-destroy`，用于关闭请求未被阻止时真正关闭窗口。

## 2026-10-17 M2-01 结构化正文编辑器

- 正文编辑器换成 Tiptap，支持加粗、斜体、小标题、引用、分隔线、链接与撤销重做；工具栏激活态跟随光标位置。
- 正文格式升到 version 2，文字改用标准行内节点；version 1 的旧正文在读取时自动升级，被编辑后保存为 v2。高于当前版本的正文拒绝打开并提示升级应用。
- 结构化正文与纯文本副本一起保存：`content_text` 由编辑器按块导出，摘要与后续搜索继续使用同一份文本。
- 新建日记的空正文改为 version 2，对应 [ADR-0004](decisions/0004-tiptap-editor-and-content-v2.md)。
- 修正读取逻辑把 v2 的文字节点误判为 v1 段落的问题，旧正文与 v2 正文现在都能正常打开。

## 2026-10-17 M2-02 图片与附件

- 编辑器工具栏新增图片按钮，可一次选择多张 PNG/JPEG 插入光标处；不支持的格式提示“只支持 PNG 和 JPEG 图片。”，正文保持不变。
- 原图复制进数据目录的 `attachments/<日记 ID>/<附件 ID>.<扩展名>`，同时生成 320 长边的 JPEG 缩略图；数据库迁移 v2 新增 `attachments` 表，记录相对路径、MIME、大小、SHA-256 和尺寸。
- 正文 image 节点只保存附件 ID 与展示尺寸，不含路径也不含 Base64；编辑器通过 `attachment` 自定义协议按 ID 读图，原文件移动或删除后仍可阅读，重启后同样可读。
- “今天”页的日记条目显示正文首图作为缩略图。
- 删除图片节点与软删除日记都不清理附件文件；永久删除与自动清理规则未定，本次不实现，见 [ADR-0005](decisions/0005-attachment-files.md)。

## 2026-10-17 M2-03 标签与回收站

- 编辑器上方新增标签栏：Enter 或逗号确认标签，标签块可单独移除。规范化（去首尾空白、内部空白折叠、比较忽略大小写）后写入，同一篇日记重复输入只保留一个，不同日记复用同一条标签记录；超过 32 个字符提示“标签最多 32 个字符。”且不写入。
- 标签在确认和移除时立即写库，不跟随正文的自动保存节奏；保存失败时标签栏保持原样并显示错误。
- 日记页脚新增“移到回收站”，执行软删除：只写 `deleted_at_utc`，日记从“今天”列表消失，正文、附件文件与标签关系都不动。
- 侧栏新增“回收站”页面，按删除时间从新到旧列出被删日记的日期、删除时刻与摘要，可一键恢复回原日期。
- 数据库迁移 v3 新增 `tags`、`entry_tags` 两张表与 `entry_tags_by_tag` 索引，见 [ADR-0006](decisions/0006-tags-and-soft-delete.md)。
- 新增六个 Tauri 命令：`list_deleted_entries`、`delete_entry`、`restore_entry`、`list_entry_tags`、`add_entry_tag`、`remove_entry_tag`。
- 修正切换日记后正文上方累积空标签栏的问题：标签栏与编辑器是同一 Fragment 的兄弟节点且用了相同 key，React 复用了旧 DOM；改为各自带前缀的 key。
- 新增两个 Rust 用例覆盖标签去重与软删除恢复，`cargo test` 现为 7 个用例。

## 2026-10-17 M2-04 回归与切页守卫

- 在真实窗口回归 A02–A09：用 SQLite 触发器注入写入失败验证 A04，用强制结束进程验证 A02 与 A05，覆盖长文粘贴、撤销重做、中文组合输入、多图导入、标签规范化与回收站恢复。

## 2026-10-17 M3-01 时间线与时间地图

- 侧栏的“时间线”与“时间地图”不再是占位页。时间线按日记日期倒序分组，每批 40 篇，滚动到底自动加载下一批，底部显示“到底了”；每行显示首图或圆点、摘要与创建时间。
- “时间地图”是按月的月历：有记录的日期显示当天篇数并用首图做底色，今天带描边；可跨月跨年翻页，相邻月的浅色格子同样可以点击；顶部显示“这个月 N 篇”。
- 点时间线的一行或月历的一天，进入那一天的日记页：标题变成具体日期，页头出现“返回时间线”或“返回时间地图”，侧栏高亮停在来源页；没有记录的日期可以直接“写这一天的第一篇”，归属那一天而不是今天。
- “今天”页改名为日记页并泛化成任意日期，`features/today/` 随之改名为 `features/journal/`；新增 `features/timeline/TimelinePage.tsx` 与 `features/calendar/CalendarPage.tsx`。
- 新增两个只读 Tauri 命令：`list_entry_dates`（按日期范围汇总每天篇数与当天首图）与 `list_timeline`（按日期倒序分页），命令总数变为十五个。
- 修复从月历进入日记页时返回按钮文案写成“返回时间线”，以及进入某一天后侧栏仍高亮“今天”、点“今天”无反应的问题。
- 新增 Rust 用例覆盖时间线分页排序与月历日期统计，`cargo test` 现为 8 个用例；A10 桌面验收记录见[迭代 005](development/iterations/iteration-005.md)。

## 2026-10-17 M3-02 搜索与筛选

- 侧栏的“搜索”不再是占位页：输入关键词即查，可再叠加标签与日期范围，三类条件同时生效。关键词对标题与正文做子串匹配，不区分大小写、不受换行与连续空格影响，`%` 与 `_` 按字面匹配。
- 标签按钮来自所有日记的标签合集，可多选，多选时取交集；日期范围含两端，只填一边表示只限起点或终点。
- 结果按日记日期倒序分批加载（每批 40 篇），每行显示日期、标题或摘要、创建时间与首图；右上角按状态显示“已读 N 篇”“找到 N 篇”“全部记录”或“没有找到”。点任意一行进入那一篇日记，页头显示“返回搜索”，侧栏高亮停在“搜索”。
- 数据库迁移 v4 给 `entries` 加 `search_text` 派生列（标题与正文折叠空白后转小写），保存时与 `excerpt` 同一次 UPDATE 重算；升级到 v4 时对旧库回填一次。取舍见 [ADR-0007](decisions/0007-search-strategy.md)。
- 新增两个 Tauri 命令：`search_entries`（关键词、标签交集与日期范围的组合查询）与 `list_tags`（筛选按钮的标签合集），命令总数变为十七个。
- 修复正在追加批次时修改筛选条件会被在途请求吞掉的问题（结果条数停在旧值），改为条件变化一律重查并丢弃过期响应；同时修正分批加载时右上角计数少报。
- 新增 Rust 用例覆盖关键词、标签与日期组合检索及分页，`cargo test` 现为 9 个用例；A11、A12 桌面验收记录见[迭代 006](development/iterations/iteration-006.md)。

## 2026-10-17 M4-01 未来信箱

- 侧栏的“未来信箱”不再是占位页：可写标题、正文与开启日期，保存后进入锁定列表；列表显示标题、开启日期与“还有 N 天开启”。
- 开启时刻取所选本地日期的 00:00:00，按写信时的系统时区换算成 UTC 存 `unlock_at_utc`，同时存 `unlock_timezone`。换时区后列表与顶栏都按写信时区解释同一个时刻，编辑时只要没改日期就沿用原时刻，不会漂移。
- 三态按当前 UTC 在读取时推进：未到期锁定、到期可打开、打开后记录 `opened_at_utc`。应用关着的时候到期，重开进页面立即正确；不依赖后台定时器。
- 到期后原信只读，可写一条回应单独保存（`reply_json` / `reply_text`），不覆盖原信，也不会改写第一次打开的时间。
- 迁移 v5 新增 `letters` 表与 `letters_by_unlock` 索引；新增七个 Tauri 命令：`list_letters`、`get_letter`、`create_letter`、`update_letter`、`delete_letter`、`open_letter`、`save_letter_reply`，命令总数变为二十四个。
- 修复四个缺陷：换时区后阅读态顶栏与列表日期对不上；换时区编辑会让开启时刻漂移；“还有 N 天”把十几秒说成 1 天；到期但尚未打开的信仍能被编辑。
- 新增两个 Rust 用例覆盖锁定到打开的状态推进、回应独立保存与跨午夜/夏令时的时刻判定，`cargo test` 现为 11 个用例；A13、A14 桌面验收记录见[迭代 007](development/iterations/iteration-007.md)。

## 2026-10-18 M5-01 Markdown 导出

- 设置页新增「导出」区块：选择目录后把全部未删除的日记写成 Markdown，图片复制到同一目录的 images/ 并用相对路径引用，导出后不依赖 Memento 也能打开。
- 正文按节点降级：小标题→`#`、引用→`>`、分隔线→`---`、加粗→`**`、斜体→`*`、删除线→`~~`、行内代码→反引号、链接→`[文本](url)`、图片→`![](images/文件名)`；不认识的节点递归取其文字。
- 文件名是「日期-标题」，标题为空时用摘要前 16 个字；Windows 不允许的字符换成空格，超长截断到 60 字；同名文件追加「 (2)」「 (3)」，不覆盖已有文件。
- 导出成功后显示导出了几篇日记、几张图片和写到哪个目录；用户在系统对话框里取消时不报错；目标不可写时返回可读错误，不留半成品。
- 新增依赖 `tauri-plugin-dialog` 与 `@tauri-apps/plugin-dialog`，capability 增加 `dialog:default`；新增 `export` 模块与 `export_entries` 命令，命令总数变为二十五个。取舍见 [ADR-0009](decisions/0009-markdown-export.md)。
- 新增 Rust 用例覆盖 Markdown 降级与重名不覆盖，`cargo test` 现为 12 个用例；A16 桌面验收记录见[迭代 008](development/iterations/iteration-008.md)。
