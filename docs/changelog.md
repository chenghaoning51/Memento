## 2026-10-17 M0 开发准备

- 新增[日记场景细化](product/journal-entry.md)：同日多篇、空日记不自动删除、四态保存状态（已保存/编辑中/保存中/保存失败）、800 ms 停止输入自动保存与最多 5 秒强制保存、切页与关闭前 flush、区分编辑撤销与保存失败恢复与回收站恢复。
- 新增[未来信件场景](product/letters.md)：开启时刻按创建时区换算 UTC、锁定/到期/已打开三状态在启动与进入页面时重算、到期后只能追加回应。
- 新增[导出与备份场景](product/backup-and-export.md)：Markdown 导出规则、完整空间备份清单、恢复预检与失败不半新半旧。
- 新增 [ADR-0002 SQLite 存储](decisions/0002-sqlite-storage.md)：Rust 侧 rusqlite + bundled，迁移使用 `PRAGMA user_version`。
- 新增 [ADR-0003 编辑器与正文格式](decisions/0003-editor-and-body-format.md)：M1 使用原生 textarea 与带版本的 `content_json`，M2 再评估 Tiptap。
- 建立最小质量流程与版本基线。

## 2026-10-17 M1 第一条可靠保存链路

- Rust 侧新增数据目录初始化：启动时在应用数据目录创建 `Memento Library/`，打开 `memento.db`，启用 WAL 与外键，按 `PRAGMA user_version` 顺序执行迁移；未知高版本直接启动失败，不写入。
- 新增五个 Tauri 命令：`library_info`、`list_entries`、`get_entry`、`create_entry`、`save_entry`。
- “今天”页接入真实数据：按本地日历日期列出当天日记、新建日记、切换日记、编辑正文。
- 自动保存：停止输入 800 ms 保存，连续输入最多 5 秒强制保存；同一时刻只有一个在途请求，排队写入最新内容；失败保留输入并显示“重试保存”。
- 切页与关闭窗口前 flush：保存失败时阻止切换并保留当前输入。
- 新增“设置”页，显示数据目录、数据库文件与模式版本。
- 新增窗口权限 `core:window:allow-destroy`，用于关闭请求未被阻止时真正关闭窗口。

## 2026-10-17 M2-01 结构化正文编辑器

- 正文编辑器换成 Tiptap，支持加粗、斜体、小标题、引用、分隔线、链接与撤销重做；工具栏激活态跟随光标位置。
- 正文格式升到 version 2，文字改用标准行内节点；version 1 的旧正文在读取时自动升级，被编辑后保存为 v2。高于当前版本的正文拒绝打开并提示升级应用。
- 结构化正文与纯文本副本一起保存：`content_text` 由编辑器按块导出，摘要与后续搜索继续使用同一份文本。
- 新建日记的空正文改为 version 2，对应 [ADR-0004](decisions/0004-tiptap-editor-and-content-v2.md)。
- 修正读取逻辑把 v2 的文字节点误判为 v1 段落的问题，旧正文与 v2 正文现在都能正常打开。

## 2026-10-17 M2-02 图片与附件

- 编辑器工具栏新增图片按钮，可一次选择多张 PNG/JPEG 插入光标处；不支持的格式提示“只支持 PNG 和 JPEG 图片。”，正文保持不变。
- 原图复制进数据目录的 `attachments/<日记 ID>/<附件 ID>.<扩展名>`，同时生成 320 长边的 JPEG 缩略图；数据库迁移 v2 新增 `attachments` 表，记录相对路径、MIME、大小、SHA-256 和尺寸。
- 正文 image 节点只保存附件 ID 与展示尺寸，不含路径也不含 Base64；编辑器通过 `attachment` 自定义协议按 ID 读图，原文件移动或删除后仍可阅读，重启后同样可读。
- “今天”页的日记条目显示正文首图作为缩略图。
- 删除图片节点与软删除日记都不清理附件文件；永久删除与自动清理规则未定，本次不实现，见 [ADR-0005](decisions/0005-attachment-files.md)。

## 2026-10-17 M2-03 标签与回收站

- 编辑器上方新增标签栏：Enter 或逗号确认标签，标签块可单独移除。规范化（去首尾空白、内部空白折叠、比较忽略大小写）后写入，同一篇日记重复输入只保留一个，不同日记复用同一条标签记录；超过 32 个字符提示“标签最多 32 个字符。”且不写入。
- 标签在确认和移除时立即写库，不跟随正文的自动保存节奏；保存失败时标签栏保持原样并显示错误。
- 日记页脚新增“移到回收站”，执行软删除：只写 `deleted_at_utc`，日记从“今天”列表消失，正文、附件文件与标签关系都不动。
- 侧栏新增“回收站”页面，按删除时间从新到旧列出被删日记的日期、删除时刻与摘要，可一键恢复回原日期。
- 数据库迁移 v3 新增 `tags`、`entry_tags` 两张表与 `entry_tags_by_tag` 索引，见 [ADR-0006](decisions/0006-tags-and-soft-delete.md)。
- 新增六个 Tauri 命令：`list_deleted_entries`、`delete_entry`、`restore_entry`、`list_entry_tags`、`add_entry_tag`、`remove_entry_tag`。
- 修正切换日记后正文上方累积空标签栏的问题：标签栏与编辑器是同一 Fragment 的兄弟节点且用了相同 key，React 复用了旧 DOM；改为各自带前缀的 key。
- 新增两个 Rust 用例覆盖标签去重与软删除恢复，`cargo test` 现为 7 个用例。
